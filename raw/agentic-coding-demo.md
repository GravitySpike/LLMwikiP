# Agentic Coding Operations Demo

Agentic coding is a software workflow where an AI agent helps plan, edit, run tools, and verify results.

## Core Concepts

- Vibe Coding: fast exploratory coding with a human and an LLM.
- Agent Coding: delegated work where an agent plans, edits, runs commands, and checks results.
- Harness Engineering: the runtime rules, tools, checks, skills, and feedback loops that make agents reliable.
- MCP Tooling: a protocol-shaped bridge between an agent and local tools such as search, read, validate, and answer.

## Why It Matters

Without a harness, an agent can produce code quickly but may miss project rules, skip tests, or lose context.
With a harness and a wiki, project knowledge becomes searchable and reusable.

## Example Workflow

1. Add one source file to `raw/`.
2. Run the wiki generator.
3. Open the viewer.
4. Ask the wiki agent a question.
5. Validate links before publishing.
