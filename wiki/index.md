## Concepts

- [[Vibe Coding]] - An exploratory development style where a human and an LLM quickly turn ideas into working code.
- [[Agent Coding]] - A development workflow where LLM agents plan, use tools, edit code, and verify results in repeated cycles.
- [[Agent Specifications]] - Documents that define an agent's role, inputs, outputs, permissions, constraints, and operating rules.
- [[Harness and Skills]] - Execution support and reusable capabilities that let agents use tools and procedures reliably.
- [[Harness Engineering]] - The engineering discipline of building the runtime wrapper, instructions, tools, checks, and feedback loops that let AI agents work safely and repeatably.
- [[Model Context Protocol]] - A standardized context protocol for connecting LLM applications to external tools and data sources.
- [[Loop and Hooks]] - Agent execution loops and hook-based extension points that run behavior at specific moments.
