# Learning Path

1. Start with [[Vibe Coding]] to explore a working idea quickly.
2. Move into [[Agent Coding]] so the agent can plan, edit, run tools, and verify results.
3. Add [[Harness Engineering]] to make the agent workflow safe and repeatable.
4. Connect tools through [[Model Context Protocol]] or a local MCP-style server.
5. Reuse procedures through [[Harness and Skills]] and project rules.
6. Stabilize behavior with [[Loop and Hooks]], linting, review points, and repeatable feedback cycles.
